# pmx: state of the build and what is left, 2026-09-13

A single page that says where this project stands, what is proved, what is merely written down, and what
remains. Every number below was measured on this tree on 2026-09-13, not copied from an agent's report.

**What pmx is.** A trading agents optimizer: a backtest arena in which populations of agents compete on
real market tapes, discover rules, and are certified only against a sealed fold and a live record. It
covers prediction markets (Kalshi, Manifold) and is built to extend to crypto, FX, equities and futures.
The build method is one written contract, exclusive file ownership per package, parallel agents, and an
adversarial gate between waves.

**Proved, not merely asserted:**

* **Determinism and replay.** Fifty seeds through the real CLI on the sealed dataset: identical run id
  and journal hash on a repeat, replays byte for byte, and the accounting invariant checked in integers
  for every agent. 94 803 journal events per run.
* **The seed genuinely changes a run.** The first fifty-seed sweep was one run repeated fifty times,
  because the stub roster consumed no randomness; an auditor caught it and AC-3 was **regraded from pass
  to partial**. A second roster whose agent draws from the substream then produced six distinct runs with
  event counts from 110 183 to 116 024.
* **The fold fix bites on the dataset that motivated it.** Verification now refuses
  `data/datasets/y2026` by recomputing `[102, 50, 135]` against the declared `[111, 46, 130]`, which is
  the inverted pyramid the review of 2026-09-08 was written about.
* **The leak tests are real.** Twelve tests across four families, read rather than only run: the
  poisoned-future test injects a future bar, a future news item, a memory record, a hive lesson, another
  agent's open forecast and the resolution of a market settling at that very bar, and asserts by content
  that none surfaces.

## 4. What is written down but not built

The contract describes far more than exists. These directories hold a docstring-only `__init__.py` and
nothing else: `src/pmx/agents/`, `src/pmx/optimizer/`, `src/pmx/live/`, `src/pmx/llm/`, `src/pmx/api/`,
`src/pmx/gateway/`, `src/pmx/features/`.

So today there is **no agent, no evolution loop, no claims ledger, no live book, no API and no new
interface**. The engine runs, the data layer builds, the sensors sense and the rule machinery tests, and
the population that has ever run through the engine is a roster of stubs.

## 6. Open defects and honest caveats

1. **AC-3 is partial, not passed.** Three binary-only stubs stand in for the eleven scripted families, so
   "the full scripted population" is only measurable once the agent package lands.
2. **AC-4 is partial.** The twelve leak tests pass, but `pmx audit leaks` does not exist: its file belongs
   to a package not yet built, and the gate deferred it rather than writing in another package's file.
3. **`run_id` does not name the population**, so a four-agent run and a three-agent run of the same seed
   share a run id and differ in their journals. Unassigned by either review.
4. **Four shapes are declared and not applied** (the last-bar drain, the previous-bar quote fallback,
   continuous calibration entries, and two result keys). Each moves a journal or a results file of every
   future run, and they ride together with the version bump in the first engine lot after amendment C1c.
5. **The dataset hash moves between two rebuilds of the same data**, because a news item carries a wall
   clock. Open since the first real build.
6. **The showcase pack has no markets**: 41 landmarks planned, 0 sourced, because no lot has been allowed
   a socket yet.
7. **The two human audits are unreviewed by construction.** The linker audit and the taxonomy audit write
   every verdict null and report a precision of zero until a person fills them in. That is honest, and
   both are gate G3's to review.
8. **Six places still ask a package to invent something**, listed in BUILD_STATE section 9.6b.

## 7. Build rules that must not be relaxed

From [HANDOFF.md](HANDOFF.md) section 2, and every one of them was learned the hard way:

1. One contract, exclusive file ownership per package, gates that may edit anything and record rulings.
2. **One Workflow invocation per lot.** A session quota killed a 39-agent run and a 9-agent run whole.
3. **Opus for every task** since 2026-09-10, when the other model's credits ran out mid-lot.
4. Long network or build commands run in the background with a polled log: three minutes without a tool
   call is a kill, and it killed two agents of this wave.
5. **At most two concurrent agents, and never two running the full test suite.** File ownership makes
   parallel writing safe and says nothing about processor contention.
6. Package reports go to a JSON file in the scratchpad that the gate reads.
7. Never the em-dash character; English in code and documents.
8. **No weakened test.** Every agent proves a touched test still fails on mutated code, and the gate that
   follows mutates the source to check.

## 8. Two things worth knowing about how this was built

**The adversarial passes pay for themselves.** The critic on amendment C1c returned twenty-four findings,
eight of them blockers, and three would have contaminated the whole of the next wave: a promoted rule's
live record read past the fold boundary; the false discovery rate control was not implementable as
written; and the one formula by which a rule reaches a trading decision had dropped the claim's
direction, so a rule saying the price is too high moved the agent's probability up.

**Mutation testing finds what reading cannot.** The sensor package widened two time windows and watched
nothing break, which is how it learned neither was covered. The data package deleted a check from the
verification entry point and it survived four whole test files. And a build test was writing fabricated
audit files into the repository's own audit tree, with a precision of zero and invented market ids,
ready to be committed as evidence of a human review that never happened. They never reached a commit.
